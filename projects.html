How to read this

This baseline trace reconstructs the session. Device-owned install and session rows can leave product fields empty, so they are filtered before event order is assessed.
Context ClickHouse · OLAP · columnar 
SELECT
    created_at,
    activity_kind,
    event_name,
    JSONExtractString(base_parameters, 'ab_group') AS ab_group
FROM analytics.realtime_events
WHERE user_id = {user_id:String}
  AND toDate(created_at) = today()
  AND activity_kind NOT IN ('install', 'session')
ORDER BY created_at DESC;

Functional tests vs. Behavioral tests

Functional checks may produce the expected result, but that does not guarantee that behavioral checks will do the same. In other words, testing a feature cannot—and should not—end with a binary true/false or passed/failed result. What happens afterward is just as important.
